# Deploy AgencyPulse to Render

**GitHub repo:** https://github.com/Rohabansari/agency-pulse

This project ships with a **Render Blueprint** (`render.yaml`) that creates:

| Service | URL (example) |
|---------|----------------|
| `agencypulse-api` | `https://agencypulse-api.onrender.com` |
| `agencypulse-web` | `https://agencypulse-web.onrender.com` |

You must create **MySQL separately** (Render does not offer MySQL). Use **Railway** (recommended, free tier).

---

## Step 1 — Create MySQL on Railway (where to create SQL)

AgencyPulse requires **MySQL 8**. Create it here:

### Railway (recommended)

1. Open **https://railway.app** and sign in with GitHub.
2. Click **New Project** → **Provision MySQL**.
3. Click the **MySQL** service → **Variables** tab.
4. Copy these values (names may vary slightly):

| Railway variable | Use as Render `DB_*` |
|------------------|----------------------|
| `MYSQLHOST` | `DB_HOST` |
| `MYSQLPORT` | `DB_PORT` |
| `MYSQLDATABASE` | `DB_DATABASE` |
| `MYSQLUSER` | `DB_USERNAME` |
| `MYSQLPASSWORD` | `DB_PASSWORD` |

5. Under **Settings** → **Networking**, enable **Public Networking** so Render can reach the database.

Keep this tab open — you will paste these into Render in Step 3.

### Alternatives

| Provider | URL | Notes |
|----------|-----|--------|
| **Aiven** | https://aiven.io | MySQL free trial |
| **PlanetScale** | https://planetscale.com | MySQL-compatible |
| **TiDB Cloud** | https://tidbcloud.com | MySQL-compatible |

Do **not** use Render PostgreSQL without code changes — this app is built for MySQL.

---

## Step 2 — Deploy on Render (Blueprint)

1. Open **https://dashboard.render.com**
2. Click **New +** → **Blueprint**
3. Connect GitHub → select **Rohabansari / agency-pulse**
4. Branch: **main**
5. Render detects `render.yaml` → click **Apply**

Two web services are created: `agencypulse-api` and `agencypulse-web`.

**First deploy may fail** until database variables are set — that is expected.

---

## Step 3 — Add database credentials to the API service

1. In Render, open **agencypulse-api** (not the web frontend).
2. Go to **Environment**
3. Add or fill in (from Railway Step 1):

```
DB_HOST=<MYSQLHOST>
DB_PORT=3306
DB_DATABASE=<MYSQLDATABASE>
DB_USERNAME=<MYSQLUSER>
DB_PASSWORD=<MYSQLPASSWORD>
```

4. Click **Save Changes** → Render redeploys the API.

5. Wait until **agencypulse-api** is **Live**.

6. Test: open `https://agencypulse-api.onrender.com/api/v1/health`  
   You should see JSON with a healthy status.

---

## Step 4 — Redeploy the frontend

After the API is live:

1. Open **agencypulse-web** in Render.
2. Click **Manual Deploy** → **Deploy latest commit**

The frontend build uses the API URL automatically via `RENDER_EXTERNAL_URL`.

3. Open `https://agencypulse-web.onrender.com` (or your assigned URL).

---

## Step 5 — Register your admin account

1. Go to your **frontend** URL (not the API URL).
2. Click **Register** → create your organization and admin user.
3. Log in and verify **Dashboard**, **Payroll** (`/admin/payroll`), and **Reports**.

---

## Step 6 — (Optional) Custom domain

1. Render → **agencypulse-web** → **Settings** → **Custom Domains**
2. Add your domain and follow DNS instructions.
3. Update **agencypulse-api** env:
   - `APP_URL` = your API URL (or keep Render URL)
   - `FRONTEND_URL` = your custom frontend URL
4. Redeploy both services.

---

## Environment reference (API)

| Variable | Required | Description |
|----------|----------|-------------|
| `APP_KEY` | Auto | Generated by Render |
| `APP_URL` | Auto | API public URL |
| `FRONTEND_URL` | Auto | Frontend public URL |
| `DB_HOST` | **Yes** | MySQL host from Railway |
| `DB_DATABASE` | **Yes** | Database name |
| `DB_USERNAME` | **Yes** | MySQL user |
| `DB_PASSWORD` | **Yes** | MySQL password |
| `DB_PORT` | No | Default `3306` |
| `CACHE_STORE` | No | Default `database` |
| `SESSION_DRIVER` | No | Default `database` |
| `QUEUE_CONNECTION` | No | Default `database` |

## Troubleshooting

| Problem | Fix |
|---------|-----|
| API build fails | Check Render logs; ensure `composer.lock` is committed |
| Database connection error | Verify Railway **public** networking; check `DB_*` values |
| Frontend shows API errors | Redeploy **agencypulse-web** after API is live |
| `/admin/payroll` 404 | Use **frontend** URL, not API URL |
| Cold start (30–60s) | Free/Starter tiers sleep when idle — upgrade or wait |
